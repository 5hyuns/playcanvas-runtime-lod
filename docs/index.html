Fewer triangles in the distance, without making LOD models.

How the runtime LOD works

Everything happens once on startup, then each frame only picks a level.

Simplify on startup

lodScript reads every indexed mesh in the entity's render component and runs meshoptimizer's simplifier for each level, using the triangle ratio and target error you set.

Swap only the index buffer

Vertex buffers stay untouched. Each level gets its own index buffer, and mesh.indexBuffer[0] is swapped at runtime, so levels share vertex memory.

Switch by camera distance

Each frame the script measures the distance to the camera and picks the level whose threshold it crossed. Remove the script and the original index buffer comes back.

Set up in the PlayCanvas Editor

  1. Upload the three files from the repository to your project.
  2. In Settings › Scripts Loading Order, place meshopt-simplifier.js before lod.js.
  3. Add lodScript to any entity with a render component. Add lodDebugUI too if you want the debug panel.

Scripting API

Force a level, read the current triangle count, or generate LODs yourself when Auto Generate is off.

  • Shared render assets share a levelMeshes are modified in place, so entities using the same render asset switch together.
  • Static meshes onlyGeneration runs once on startup; it isn't meant for meshes that change at runtime.
const lod = entity.script.lodScript;

lod.setManualMode(true);  // stop distance-based switching
lod.setLODLevel(2);       // force LOD2
lod.getCurrentLOD();      // current level
lod.getCurrentTriangleCount();
lod.getCameraDistance();

lod.generate().then(() => {
  // generate manually when Auto Generate is off
});
